Onward Daily Build v2.1.0-daily.20260731.1

Changes since v2.1.0-daily.20260722.1.

New Features

  • Drag to rearrange Tasks: press and hold a Task header, or use its dropdown, to move a terminal to another slot — the PTY session, scrollback and running command all travel with it. Dragging inserts and shifts rather than swapping, the same as VS Code editor groups, and Task numbers follow position so Cmd+1..8 keeps addressing the same slots
  • The Prompt panel's Task selector is now a scale model of the real Task grid: a 6-Task layout reads 3x2 on both sides instead of 3x2 against 2x3, and custom layouts are reproduced cell for cell, row spans included
  • Quit confirmation now names what is actually running: Onward enumerates each terminal's child processes and lists the active jobs and their Tasks before quitting, instead of showing a generic dialog that could silently kill a running agent task
  • Onward now records whether each session ended cleanly and surfaces a dismissible notice on the next launch when it did not — force quit, power loss and freezes leave no crash report, so these exits were previously invisible
  • Diagnostic bundles now carry terminal screen-mode and scrollback diagnostics, so "scrolling up in a full-screen TUI finds no history" can be root-caused from a bundle alone (no user-visible behavior change)

Bug Fixes

  • Upgrade to Electron 43.2.0, which eliminates the ANGLE-Metal GPU-process crash behind the white screen that appeared after the app sat hidden with live terminal output, along with the file-watcher abort during quit
  • Rebuild after a GPU-process crash in two phases — dispose everything, then recreate everything — so the shared glyph atlas is released and a poisoned cache entry is evicted instead of being carried into the new terminals; a crash that arrives while the window is hidden defers its rebuild until the window is visible again
  • Stop the visibility watchdog from judging or nudging occluded background windows, and check immediately on window focus, show, and input instead of waiting out a cooldown — worst-case recovery from a stuck window drops from over five minutes to roughly two seconds
  • Git Diff: reopening a file whose git state had changed, for example from untracked to staged, could show the previous diff, land the viewport on a line from that stale content, and leave every unchanged region expanded
  • Git Diff: when a file changes on disk while you are viewing it, the viewport now converges to the correct position on its own, and says so only when you had deliberately scrolled somewhere else
  • Terminal: restore working-directory detection on locked-down Windows machines where script-execution policy blocked the PowerShell shell-integration script — the failure left Git Diff and Git History unusable, and the shell-integration status is now reported per terminal
  • Terminal: the manual change-working-directory action now waits for the shell to confirm the new directory before persisting it, refuses to type into a full-screen TUI holding the alternate screen, and explains why when it cannot proceed
  • Git Diff and Git History: a slow repository probe on a network or mapped drive that exceeded its time budget was silently misreported as "not a repository", and now shows a dedicated timeout state with a retry that bypasses the backoff
  • Project Editor HTML preview: clicking a table-of-contents entry now scrolls on every click, no longer latches the loading overlay over the page, and lands on the right section when a zoom factor is applied
  • Restore the border colour on Task cards 7 and 8, which rendered without an accent because the layout referenced a colour variable that does not exist
