Onward Daily Build v2.1.0-daily.20260713.1

Changes since v2.1.0-daily.20260711.1.

New Features

  • Add HTML preview navigation (back / forward / reload / home)
  • Add OS "Open with Default Application" and "Reveal in Finder / File Explorer" context actions on all file surfaces
  • Auto-preserve Prompt editor input when double-clicking a history entry: the current input is saved to history first, then the selected entry loads — typed content is never silently discarded

Bug Fixes

  • Keep WebGL contexts alive across window occlusion — fixes all terminals briefly showing a white placeholder for 1–3 seconds after switching back from another desktop (Space)
  • Viewport-aware placement for every right-click context menu — menus opened near the window edge now flip above the cursor instead of being cut off (Project Editor, Git Diff, Git History, terminal, Prompt surfaces)
  • Git Diff freshness: fix the content-cache stale-token race (TOCTOU) and fence warm-status reuse behind the latest mutation invalidation
  • Per-Task view memory survives multi-terminal use
  • HTML preview scroll capture is gated on the home document so scroll memory stays correct across in-preview navigation
